# Sea window sample artwork

`sea-window.png` is the original 1586 × 992 PNG bundled for the optional Morupixel learning sample. It was generated on 2026-09-21 with the built-in `image_gen.imagegen` tool from a prompt describing an open white seaside window, ivory curtain, glass vase and flowers, and a sunlit blue ocean. Two user-provided images informed the mood only; they were inspected, not passed as generation inputs or reused. The generated file was copied without enlargement or editing. SHA-256: `1f8a4eddd924c4cde283aca676fb5121ceae9cb256cd6e4c56395d611bca5822`.

Morupixel starts with an empty workspace. Choosing Learn or Learn → Open Sample opens this embedded PNG as a single raster layer in an editable document; it is not loaded automatically at startup. Optional title and small-caption layers are editable text in a hidden group, so the sample initially displays the artwork without added text.

The artwork is newly generated for the Morupixel demo and is not taken from the original Compositor or a third-party photograph. Its attribution is separate from the upstream code notices.
