# PDF · PSD · AI · DWG/DXF 파일

Preview 9부터 PDF, PDF 호환 AI, PSD/PSB, DWG/DXF를 열 수 있습니다. 이미지 편집에 필요한 외형과 지원되는 기본 레이어를 가져오는 기능입니다. 원본 디자인 문서나 CAD 객체의 모든 편집 속성을 보존하는 호환 엔진은 아닙니다. 원본 파일을 덮어쓰지 않으며 편집한 작업은 `.moruproj`로 저장하세요.

## 가져오기

1. **파일 → 열기 (Ctrl+O)**에서 파일을 고르거나 편집기로 파일을 끌어 놓습니다.
2. 처음 미리보기는 자동으로 만들어집니다. CAD는 **부분별로 편집 (추천)**이 선택되고 PDF/AI는 저장된 레이어를 유지합니다. PDF/AI의 페이지·아트보드는 번호로 선택합니다.
3. 필요한 경우 **세부 설정**을 펼쳐 CAD의 도면 배치·작업 크기, PDF/AI의 이미지 해상도, 벡터 유지 여부를 바꿉니다. CAD 작업 크기는 가로·세로 중 긴 쪽의 픽셀 수입니다. 설정을 바꾸면 **미리보기 새로고침**을 누르세요.
4. 미리보기를 확인한 뒤 **가져오기**를 누릅니다. 크기·항목 수와 원본과 달라질 수 있는 부분은 **변환 안내**를 펼치면 볼 수 있습니다. 취소하면 현재 문서는 변경되지 않습니다.

**가져오기** 명령으로 기존 문서에 배치하면 가져온 레이어가 한 그룹으로 추가됩니다. 레이어 이름·표시 상태·상대 위치를 유지하고 전체 그룹을 캔버스에 맞춥니다. PDF는 선택한 한 페이지/아트보드씩 열며 다른 페이지는 다시 열어 별도 탭으로 가져옵니다.

Preview 25에서는 CAD와 벡터를 유지한 PDF/AI를 **도면 레이어** 탭에 파일 하나로 묶어 표시합니다. CAD의 같은 원본 레이어는 한 행으로 모아서 보여주며, 내부 객체는 계속 개별 편집할 수 있습니다. 표시를 위해 합칠 때 원래 겹침 순서는 바뀌지 않습니다. 사진·PSD 이미지는 **사진 레이어** 탭에서 관리합니다. 새 도면 그룹과 대지는 `.moruproj` 버전 5에 저장되므로 다시 열 때 Preview 25 이상을 사용하세요.

| 형식 | 읽기 | 쓰기와 주요 제한 |
| --- | --- | --- |
| `.moruproj` 재료 맵핑 | Preview 26부터 포맷 6의 내장 원본 재료·영역·패턴 설정 읽기 | 재료 또는 영역이 있는 문서는 포맷 6으로 저장. 다시 열 때 Preview 26 이상 필요. [재료 맵핑](MATERIAL_MAPPING.md) |
| PDF | 선택한 페이지를 36~600 DPI로 변환. 저장된 OCG 레이어의 이름·표시·잠금 상태를 유지해 투명 픽셀 레이어로 분리 | 한 페이지 RGB PDF. **한 장으로 합치기** 또는 맨 위 레이어·그룹마다 PDF 레이어(OCG)를 만드는 **레이어 나누기**. 선·문자·도형은 벡터로 유지 |
| AI `.ai` | 저장할 때 **PDF 호환 파일** 옵션을 켠 AI 파일의 PDF 부분 | **.ai · 레이어 유지 (PDF 호환)**: PDF 레이어를 담은 PDF 호환 .ai. AI 전용 편집 데이터와 원본 패스·앵커 편집은 미지원. 구형 PostScript AI는 PDF로 변환 후 가져오기 |
| PSD `.psd`, `.psb` | RGB 또는 회색조 **8비트**. 기본은 저장된 합성 이미지. 선택적으로 픽셀 레이어·그룹·위치·표시·불투명도·래스터 마스크·클리핑·지원 혼합 모드 | RGB8 PSD. **레이어 유지**(그룹·마스크·클리핑 포함) 또는 **한 장으로 합치기**. PSB 출력, CMYK/Lab/16·32비트 입력은 미지원 |
| CAD 도면 `.dwg`, `.dxf` | 모델 공간·배치·로컬 외부참조의 2D 벡터 형상 유지. 원본 객체별 / 레이어별 / 전체를 선택해 가져오기 | 객체별 이동·크기·회전·표시와 그룹 편집 가능. CAD 제약·실측 치수·원본 패스의 점 편집 및 DWG/DXF 쓰기는 미지원 |

PSD 개별 레이어 모드는 그룹을 그룹으로 가져오고(표시·불투명도·마스크 포함, 최대 16단계), 조정·채우기 레이어나 지원하지 않는 혼합 모드가 있으면 가져오기를 중단하고 합성 이미지 모드를 안내합니다. 레이어는 파일에 저장된 순서(아래에서 위로)대로 쌓습니다. Preview 35 이하의 Morupixel이 저장한 레이어 PSD는 위에서 아래 순서로 저장되어 있어, 그 버전의 고정된 파일 구성(해상도 리소스만 있고 모든 레이어가 캔버스 전체 크기의 비압축 채널)으로 알아보고 원래 순서로 쌓은 뒤 가져오기 안내에 표시합니다. 지금 버전의 PSD에는 Morupixel 이름이 담긴 버전 리소스(1057)가 들어 있어 이후에도 구별할 수 있습니다. 내용이 없는 레이어도 이름과 순서를 유지합니다. 문자와 내장 개체는 저장된 픽셀로 읽으며 레이어 효과·벡터 마스크는 재현하지 않습니다. 호환용 합성 이미지를 함께 저장하지 않은 PSD는 합성 모드로 읽지 못할 수 있습니다. PSD 내장 ICC는 적용하지 않으므로 색상 정확도가 중요하면 파일을 만든 프로그램에서 sRGB/8비트 사본을 준비하세요.

PDF/AI의 레이어는 PDF 부분에 저장된 OCG(Optional Content Group)를 사용합니다. 숨긴 레이어의 픽셀도 가져오며, 페이지에 내용이 없는 레이어도 이름과 순서를 유지합니다. 그리기 순서가 교차하는 레이어는 외형을 유지하기 위해 이름에 번호를 붙여 나눕니다. PDF 용지는 별도 흰색 배경 레이어입니다. 복합 가시성 조건·중첩 가시성·인라인 이미지가 있는 일부 PDF는 레이어 유지를 끄고 가져와야 합니다. 레이어 사이의 특수 혼합 효과는 원본과 다를 수 있습니다. AI의 비공개 편집 데이터나 PDF 부분에 없는 레이어는 복원하지 않습니다. 레이어 모드의 PDF/AI 파일은 512MiB 이하, 최대 128개 결과 레이어와 8GiB 픽셀 예산을 적용합니다.

DWG/DXF에서는 선·원·호·타원·폴리라인·스플라인·솔리드·일부 문자·블록·치수 블록을 그립니다. 배치가 있으면 첫 배치를 자동 선택하며 모델 공간이나 다른 배치로 바꿀 수 있습니다. **도면 크기에 맞춰 대지 만들기**를 켜면 모델 공간은 도면 범위, 배치는 출력 용지 크기(용지 설정의 크기·방향·여백 기준, 도면을 둘러싸지 않으면 도면 가운데 기준)로 대지를 만듭니다. 2D 뷰포트의 이동·축척·회전·사각/폴리라인/원 경계와 뷰포트별 동결 레이어를 적용합니다. 로컬 외부참조는 원본 DWG 기준 상대경로 또는 저장된 절대경로로 읽으며, 없으면 같은 폴더의 같은 파일명을 확인합니다. 참조 경로 문자열이 남은 결합 블록도 실제 플래그로 구분해 정상 표시합니다. 외부참조는 최대 31개 파일/512MiB, 중첩 16단계, 도형 방문 100만 회와 변환 점 800만 개로 제한하며 순환·누락 참조를 안내합니다. 네트워크 공유의 외부참조는 지원하지 않습니다.

해치는 기본적으로 경계선을 표시하고, **도면 정리**를 켜면 닫힌 경계를 추천 재질이나 사용자 재질 이미지로 채운 재료 맵핑 레이어를 선 아래에 추가합니다(문서당 영역 128개, 영역 경로 64KiB 한도를 넘는 해치는 경계선만 유지). 재질 레이어는 도면 그룹 안에 남아 함께 움직이지만 **사진 레이어** 탭에 표시되어 불투명도·혼합·마스크를 편집합니다. 원본 해치 패턴 선 자체는 재현하지 않습니다. 도면 정리의 선 굵기·농도는 레이어 이름으로 추정한 역할에 따르며 원본 CTB·선굵기 값을 읽는 것은 아닙니다. SHX, 복잡한 문자 서식, 원본 선종류·선굵기·CTB 및 실측 축척은 보존하지 않습니다. Z 좌표는 XY로 투영하며 기울어진 3D 뷰포트, REGION, WIPEOUT 등 미지원 객체를 안내합니다. 원본과 동일한 출력 도면이 필요하면 CAD 프로그램에서 PDF로 출력한 파일을 가져오세요.

DWG 리더의 지원 파일 세대는 R14~2018 형식(AC1014~AC1032), DXF는 R12~2018 형식(AC1009~AC1032)입니다. 같은 확장자라도 버전과 객체 종류에 따라 읽기 결과가 달라집니다. 모든 세대의 실파일을 검증한 것은 아닙니다.

### 지도 데이터 (.osm · GeoJSON)

**파일 › 지도 만들기 (OSM 파일)…**는 openstreetmap.org의 내보내기로 받은 OpenStreetMap XML(`.osm`, 1GB 이하)과 OpenStreetMap 태그가 있는 GeoJSON(`.geojson`, 256MB 이하)을 읽어 지도 포스터나 대지 위치도를 새 문서로 만듭니다. 길·철도·물·녹지·건물은 종류별 벡터 레이어로, multipolygon 관계는 구멍을 유지한 면으로, 해안선은 영역 안의 바다로 그립니다. XML은 스트리밍으로 읽고 DTD·외부 엔터티를 처리하지 않으며 점 1,500만·길과 면 250만·관계 50만 개가 한도입니다. `.pbf`·`.o5m`은 지원하지 않습니다. 만든 지도는 웹 메르카토르 투영과 1px의 실제 거리를 저장하며 레이어로 나눈 PDF·.ai에서 벡터로 내보냅니다. [지도 포스터 · 대지 위치도](MAPS.md)

## CAD 편집 방식

- **부분별로 편집 (추천)**: 닫힌 폴리라인 사각형은 한 객체, 독립된 LINE 네 개는 네 객체입니다. 선의 끝점이 닿아 있어도 별도 원본 객체는 자동으로 합치지 않습니다. 블록의 지원 도형은 각각 선택할 수 있고, 치수·해치의 구성 선은 해당 객체 안에서 함께 유지합니다.
- **레이어별로 편집**: 같은 CAD 레이어의 형상을 묶어 선택합니다.
- **한 장으로 가져오기**: 도면의 형상을 하나로 선택합니다.

원본 레이어 이름은 그룹 이름으로 유지합니다. 서로 다른 레이어의 그리기 순서가 교차하면 외형 보존을 위해 같은 이름의 그룹이 여러 번 나올 수 있습니다. 그룹을 펼치거나 캔버스에서 객체를 클릭해 안의 도형을 선택하세요. 이동·변형·순서·표시 변경과 실행 취소를 지원하고 `.moruproj`로 저장하면 객체 구분이 유지됩니다. 기존에 한 이미지로 가져온 도면은 원본 DWG/DXF를 다시 가져와야 합니다. PNG/JPEG나 합쳐진 PDF 이미지에서 원래 객체를 추정해 분리하는 기능은 아닙니다.

객체·그룹을 포함해 최대 **32,768개 항목**이며, 이미지·조정 레이어는 그 안에서 최대 **128개**입니다. 픽셀·마스크 합계 8GiB와 벡터 원본 512MiB 제한도 함께 적용됩니다. 한도를 넘으면 안내 후 가져오기를 중단합니다. **레이어별로 편집**이나 **한 장으로 가져오기**로 바꾸거나 원본에서 필요한 범위를 나눠 가져오세요. 공유 그룹 이미지를 저장하는 새 프로젝트 형식(v4)은 **Preview 21 이상**에서 다시 열 수 있습니다.

## 내보내기

**파일 → PDF · PSD · AI로 내보내기**에서 형식을 고르거나, 명령 찾기(Ctrl+K)에서 같은 이름을 검색합니다. **내보내기 미리보기**(PNG·JPEG·TIFF) 창의 **PDF · PSD · AI로 내보내기…**도 같은 창을 엽니다. 창에는 형식마다 한 줄 설명과, 현재 문서에서 무엇이 그대로 남고 무엇이 픽셀로 바뀌는지가 표시됩니다. 저장 창의 파일 형식과 확장자는 고른 형식을 따릅니다.

| 형식 | 이런 때 | 유지 | 픽셀로 바뀌거나 빠지는 것 |
| --- | --- | --- | --- |
| **PDF · 한 장으로 합치기 (인쇄·공유용)** | 인쇄·전달 | 한 페이지. **선과 글자를 벡터로 유지**를 켜면 선·문자·도형·원본 PDF 벡터·사진(원본 해상도)을 그대로 담음 | 마스크·클리핑·불투명도·혼합 모드·원근·조정·재료가 있는 부분은 문서 해상도 이미지. 끄면 전체가 한 장의 이미지. 숨긴 레이어는 제외 |
| **PDF · 레이어 나누기 (레이어별 켜고 끄기)** | 레이어를 켜고 끄며 검토 | 맨 위 레이어·그룹마다 PDF 레이어(OCG) 하나. 이름(한글 포함)·표시·잠금·순서. 도면 파일 묶음은 안의 도면 레이어별로 나눔. 벡터 유지 방식은 위와 같음 | 그룹 안의 레이어는 그 PDF 레이어 안에 함께 그려지며, 그룹 안에서 숨긴 레이어는 제외. 맨 위 조정 레이어는 아래 내용에 적용한 결과 이미지 |
| **.psd · 레이어 유지** | 다른 이미지 편집 앱에서 이어 작업 | 레이어·그룹(폴더, 최대 16단계)·이름·순서·표시·불투명도·혼합 모드·클리핑·레이어 마스크. 각 레이어는 내용 크기만큼 잘라 저장 | 문자·도형·벡터·재료 레이어는 보이는 모습의 픽셀 레이어. 조정 레이어는 아래 레이어에 적용한 결과 픽셀(불투명도·혼합 모드·마스크는 유지). 원근 변형 그룹은 한 장. 잠금은 저장하지 않음 |
| **.psd · 한 장으로 합치기** | 레이어가 128개를 넘거나 한 장만 필요할 때 | 현재 모습 한 장과 합성 이미지 | 레이어 구조 |
| **.ai · 레이어 유지 (PDF 호환)** | 벡터 디자인 앱으로 전달 | **PDF · 레이어 나누기**와 같은 내용을 확장자 `.ai`로 저장한 PDF 호환 파일 | AI 전용 편집 데이터는 없음. 여는 앱에 따라 레이어 표시 방식이 다를 수 있음 |

- **.psd · 레이어 유지**는 최대 128개 픽셀 레이어입니다. 넘으면 가장 깊은 그룹부터 각각 한 장의 레이어로 합쳐 위쪽 구조를 유지하고, 그래도 넘으면 저장하지 않고 **.psd · 한 장으로 합치기**를 안내합니다. 한 변 30,000px, 레이어 데이터 2GB 한도를 먼저 확인합니다. 그룹은 혼합 모드가 모두 기본이면 통과(pass-through) 폴더로, 아니면 격리된 폴더로 저장해 같은 모습을 유지합니다.
- 조정 레이어 결과는 아래 레이어가 불투명할 때 원본과 같고, 반투명한 가장자리에서는 조금 다를 수 있습니다.
- PDF 레이어는 최대 127개입니다. 넘으면 저장하지 않고 **PDF · 한 장으로 합치기**를 안내합니다. PDF 혼합 모드는 PDF 표준 혼합 상태로 기록합니다.
- 모든 출력은 RGB입니다. 기존 **CMYK TIFF 출력**은 [CMYK 안내](CMYK.md)를 참고하세요. 원본 편집 속성은 `.moruproj`에도 함께 보관해야 합니다.

## 사진 현상과 사용자 브러시 저장

Preview 13의 **사진 현상**은 이미 가져온 RGB 8비트 이미지에 적용하는 비파괴 보정입니다. 카메라 RAW 파일을 해독하는 기능이나 다른 현상 프로그램과 같은 결과를 보장하는 호환 엔진은 아닙니다. 지원하는 사진·PDF·AI·PSD·CAD를 이미지로 가져온 뒤 같은 보정을 적용할 수 있습니다.

- `.moruproj`는 사진 현상의 13개 조절값·마스크·레이어 속성을 저장합니다. 이 조정 레이어가 있는 작업은 **Preview 13 이상**에서 다시 열어 편집하세요.
- 원작 `.comp`는 사진 현상 조정을 지원하지 않으므로 해당 레이어가 있으면 내보내기를 거부하고 안내합니다. 조절값 보관에는 `.moruproj`, 외형 전달에는 합성 이미지·PDF·PSD를 사용하세요. **.psd · 레이어 유지**는 사진 현상을 포함한 조정 레이어를 아래 레이어에 적용한 결과 픽셀로 담으며 조절값은 저장하지 않습니다.
- 사용자 브러시 모양은 PNG/JPEG/BMP/TIFF에서 가져옵니다. 파일 **32 MiB 이하**, 한 변 65,535px·전체 536,870,897픽셀 이하가 적용되며, 긴 변 최대 256px의 모양으로 축소해 `%LOCALAPPDATA%\Morupixel\Brushes`에 보관합니다. 다중 프레임 이미지는 첫 프레임만 사용하고 `.abr` 브러시 파일은 지원하지 않습니다.
- 브러시 라이브러리는 개인 설정이며 `.moruproj`에 들어가지 않습니다. 이미 그린 획은 픽셀로 저장되므로 다른 PC에서도 보입니다. 다른 PC에서 같은 브러시를 새로 사용하려면 원본 이미지를 다시 가져오거나 위 사용자 브러시 폴더를 옮기세요.
- 브러시 내 프리셋(모양·크기·경도·농도·회전·간격)은 `%LOCALAPPDATA%\Morupixel\brush-presets.json`에 최대 64개 보관합니다. 손상된 파일이나 256 KiB를 넘는 파일은 빈 목록으로 읽고, 잘못된 항목은 건너뛰며 값은 패널 범위로 맞춥니다. 이미지 모양은 ID로만 가리키므로 다른 PC로 옮길 때는 Brushes 폴더도 함께 옮기세요.

## 실행 환경과 한도

Windows 10 버전 2004(빌드 19041) 이상 또는 Windows 11, x64가 필요합니다. PDF 렌더링은 Windows 내장 엔진을 사용하고 DWG/DXF 리더는 앱에 포함합니다. 별도 디자인·CAD 프로그램 설치, 외부 변환 프로그램, 업로드 서비스는 필요하지 않습니다.

PDF·AI·PSD/PSB·DWG/DXF 입력 파일은 최대 **8GiB**입니다. 일반 PNG·JPEG 등의 이미지 열기에는 별도 파일 바이트 제한이 없습니다. 모든 입력에는 한 변 **65,535px**, 전체 **536,870,897픽셀(약 536.9MP)**, 최대 32,768개 객체·그룹(이미지·조정 레이어는 최대 128개), 레이어 픽셀/마스크 합계 **8GiB**의 문서 한도가 적용됩니다. PDF/PSD 및 기존 CAD 레이어별 모드의 결과 레이어 한도는 128개입니다. 가로·세로와 전체 픽셀 제한을 모두 만족해야 합니다. `.moruproj`의 레이어별 PNG 항목은 최대 **4GiB**, 문서 메타데이터는 최대 **32MiB**까지 읽습니다.

PSB 입력은 위 이미지 한도를 사용합니다. **PSD 출력은 한 변 30,000px**의 형식 한도를 유지하며 PSB 출력은 지원하지 않습니다. CAD 미리보기 긴 변은 256~4,096px입니다. 암호 PDF는 암호를 해제한 사본이 필요합니다.

실행 취소는 최대 50개 항목과 별도 보관 픽셀 **192MiB** 범위이므로 큰 편집은 실행 취소 기록을 남기지 못할 수 있습니다. 디코딩·합성·편집에 추가 전체 크기 버퍼가 필요하며, 실제로 열고 편집할 수 있는 크기는 사용 가능한 메모리·코덱·작업 내용에 따라 달라집니다.

## 검증과 출처

회귀 테스트는 실제 외부 PSD·DWG 샘플, 독립 생성한 다중 페이지 PDF와 DXF, PSD/PSB 압축·마스크·경계 검사, 파일 쓰기 실패 시 원본 보존을 확인합니다. 출력 PSD는 독립적인 Pillow 디코더로도 픽셀과 투명도를 확인했습니다. 레이어를 유지한 PSD는 앱의 가져오기와 별도 PSD 파서(PsdSharp)로 다시 읽어 그룹 계층·이름·순서·불투명도·혼합 모드·마스크·클리핑을 검사하고, 레이어를 나눈 PDF·.ai는 PDF 레이어 수·이름·표시 상태와 다시 가져오기를 검사합니다. 형식을 만든 프로그램에서의 왕복 편집이나 Windows 10 실기기 테스트는 수행하지 않았습니다.
