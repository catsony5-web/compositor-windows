# PDF · Photoshop · Illustrator · AutoCAD 파일

Preview 9부터 PDF, PDF 호환 AI, PSD/PSB, DWG/DXF를 열 수 있습니다. 이미지 편집에 필요한 외형과 지원되는 기본 레이어를 가져오는 기능입니다. Adobe 문서나 CAD 객체의 모든 편집 속성을 보존하는 호환 엔진은 아닙니다. 원본 파일을 덮어쓰지 않으며 편집한 작업은 `.moruproj`로 저장하세요.

## 가져오기

1. **파일 → 열기 (Ctrl+O)**에서 파일을 고르거나 편집기로 파일을 끌어 놓습니다.
2. 처음 미리보기는 자동으로 만들어집니다. CAD는 **부분별로 편집 (추천)**이 선택되고 PDF/AI는 저장된 레이어를 유지합니다. PDF/AI의 페이지·아트보드는 번호로 선택합니다.
3. 필요한 경우 **세부 설정**을 펼쳐 CAD의 도면 배치·작업 크기, PDF/AI의 이미지 해상도, 벡터 유지 여부를 바꿉니다. CAD 작업 크기는 가로·세로 중 긴 쪽의 픽셀 수입니다. 설정을 바꾸면 **미리보기 새로고침**을 누르세요.
4. 미리보기를 확인한 뒤 **가져오기**를 누릅니다. 크기·항목 수와 원본과 달라질 수 있는 부분은 **변환 안내**를 펼치면 볼 수 있습니다. 취소하면 현재 문서는 변경되지 않습니다.

**가져오기** 명령으로 기존 문서에 배치하면 가져온 레이어가 한 그룹으로 추가됩니다. 레이어 이름·표시 상태·상대 위치를 유지하고 전체 그룹을 캔버스에 맞춥니다. PDF는 선택한 한 페이지/아트보드씩 열며 다른 페이지는 다시 열어 별도 탭으로 가져옵니다.

| 형식 | 읽기 | 쓰기와 주요 제한 |
| --- | --- | --- |
| PDF | 선택한 페이지를 36~600 DPI로 변환. 저장된 OCG 레이어의 이름·표시·잠금 상태를 유지해 투명 픽셀 레이어로 분리 | PDF 출력은 한 페이지 RGB 합성 이미지. 원본 벡터·문자는 픽셀로 편집 |
| Illustrator `.ai` | Illustrator에서 **Create PDF Compatible File / PDF 호환 파일 만들기**를 켜서 저장한 AI의 PDF 부분 | PDF로 출력 가능. AI 전용 저장과 원본 패스·앵커 편집은 미지원. 구형 PostScript AI는 PDF로 변환 후 가져오기 |
| Photoshop `.psd`, `.psb` | RGB 또는 회색조 **8비트**. 기본은 저장된 합성 이미지. 선택적으로 기본 픽셀 레이어·위치·표시·불투명도·래스터 마스크·지원 혼합 모드 | RGB8 PSD로 합성 이미지 또는 기본 픽셀 레이어 출력. PSB 출력, CMYK/Lab/16·32비트 입력은 미지원 |
| AutoCAD `.dwg`, `.dxf` | 모델 공간·배치·로컬 외부참조의 2D 벡터 형상 유지. 원본 객체별 / 레이어별 / 전체를 선택해 가져오기 | 객체별 이동·크기·회전·표시와 그룹 편집 가능. CAD 제약·실측 치수·원본 패스의 점 편집 및 DWG/DXF 쓰기는 미지원 |

PSD 개별 레이어 모드는 그룹·조정 레이어·지원하지 않는 혼합 모드가 있으면 가져오기를 중단하고 합성 이미지 모드를 안내합니다. 문자와 스마트 오브젝트는 저장된 픽셀로 읽으며 레이어 효과·벡터 마스크는 재현하지 않습니다. Photoshop에서 호환용 합성 이미지를 저장하지 않은 파일은 합성 모드로 읽지 못할 수 있습니다. PSD 내장 ICC는 적용하지 않으므로 색상 정확도가 중요하면 Photoshop에서 sRGB/8비트 사본을 준비하세요.

PDF/AI의 레이어는 PDF 부분에 저장된 OCG(Optional Content Group)를 사용합니다. 숨긴 레이어의 픽셀도 가져오며, 페이지에 내용이 없는 레이어도 이름과 순서를 유지합니다. 그리기 순서가 교차하는 레이어는 외형을 유지하기 위해 이름에 번호를 붙여 나눕니다. PDF 용지는 별도 흰색 배경 레이어입니다. 복합 가시성 조건·중첩 가시성·인라인 이미지가 있는 일부 PDF는 레이어 유지를 끄고 가져와야 합니다. 레이어 사이의 특수 혼합 효과는 원본과 다를 수 있습니다. AI의 비공개 편집 데이터나 PDF 부분에 없는 레이어는 복원하지 않습니다. 레이어 모드의 PDF/AI 파일은 512MiB 이하, 최대 128개 결과 레이어와 8GiB 픽셀 예산을 적용합니다.

DWG/DXF에서는 선·원·호·타원·폴리라인·스플라인·솔리드·일부 문자·블록·치수 블록을 그립니다. 배치가 있으면 첫 배치를 자동 선택하며 모델 공간이나 다른 배치로 바꿀 수 있습니다. 2D 뷰포트의 이동·축척·회전·사각/폴리라인/원 경계와 뷰포트별 동결 레이어를 적용합니다. 로컬 외부참조는 원본 DWG 기준 상대경로 또는 저장된 절대경로로 읽으며, 없으면 같은 폴더의 같은 파일명을 확인합니다. 참조 경로 문자열이 남은 결합 블록도 실제 플래그로 구분해 정상 표시합니다. 외부참조는 최대 31개 파일/512MiB, 중첩 16단계, 도형 방문 100만 회와 변환 점 800만 개로 제한하며 순환·누락 참조를 안내합니다. 네트워크 공유의 외부참조는 지원하지 않습니다.

해치는 경계선만 표시합니다. SHX, 복잡한 문자 서식, 원본 선종류·선굵기·CTB 및 실측 축척은 보존하지 않습니다. Z 좌표는 XY로 투영하며 기울어진 3D 뷰포트, REGION, WIPEOUT 등 미지원 객체를 안내합니다. 원본과 동일한 출력 도면이 필요하면 AutoCAD에서 PDF로 출력한 파일을 가져오세요.

DWG 리더의 지원 파일 세대는 R14~2018 형식(AC1014~AC1032), DXF는 R12~2018 형식(AC1009~AC1032)입니다. 같은 확장자라도 버전과 객체 종류에 따라 읽기 결과가 달라집니다. 모든 세대의 실파일을 검증한 것은 아닙니다.

## CAD 편집 방식

- **부분별로 편집 (추천)**: 닫힌 폴리라인 사각형은 한 객체, 독립된 LINE 네 개는 네 객체입니다. 선의 끝점이 닿아 있어도 별도 원본 객체는 자동으로 합치지 않습니다. 블록의 지원 도형은 각각 선택할 수 있고, 치수·해치의 구성 선은 해당 객체 안에서 함께 유지합니다.
- **레이어별로 편집**: 같은 CAD 레이어의 형상을 묶어 선택합니다.
- **한 장으로 가져오기**: 도면의 형상을 하나로 선택합니다.

원본 레이어 이름은 그룹 이름으로 유지합니다. 서로 다른 레이어의 그리기 순서가 교차하면 외형 보존을 위해 같은 이름의 그룹이 여러 번 나올 수 있습니다. 그룹을 펼치거나 캔버스에서 객체를 클릭해 안의 도형을 선택하세요. 이동·변형·순서·표시 변경과 실행 취소를 지원하고 `.moruproj`로 저장하면 객체 구분이 유지됩니다. 기존에 한 이미지로 가져온 도면은 원본 DWG/DXF를 다시 가져와야 합니다. PNG/JPEG나 합쳐진 PDF 이미지에서 원래 객체를 추정해 분리하는 기능은 아닙니다.

객체·그룹을 포함해 최대 **32,768개 항목**이며, 이미지·조정 레이어는 그 안에서 최대 **128개**입니다. 픽셀·마스크 합계 8GiB와 벡터 원본 512MiB 제한도 함께 적용됩니다. 한도를 넘으면 안내 후 가져오기를 중단합니다. **레이어별로 편집**이나 **한 장으로 가져오기**로 바꾸거나 원본에서 필요한 범위를 나눠 가져오세요. 공유 그룹 이미지를 저장하는 새 프로젝트 형식(v4)은 **Preview 21 이상**에서 다시 열 수 있습니다.

## 내보내기

**파일 → PDF / Photoshop 파일로 내보내기…**에서 다음 중 선택합니다.

- **PDF · 합성 이미지**: 투명도를 포함한 현재 합성 결과를 한 페이지에 담습니다. 물리 크기는 문서 픽셀 크기와 DPI로 정합니다. Illustrator에서도 이미지로 열 수 있습니다.
- **PSD · 합성 이미지**: 현재 외형을 한 픽셀 레이어와 합성 이미지로 저장합니다.
- **PSD · 픽셀 레이어**: 기본 레이어의 이름·표시·불투명도·혼합 모드를 저장합니다. 문자·도형·변형·마스크는 각 레이어의 픽셀에 적용됩니다. 그룹·조정·클리핑이 있는 문서는 합성 PSD를 선택하세요. 무압축 PSD이므로 저장 파일은 클 수 있습니다.

PDF/PSD 출력은 RGB입니다. 기존 **CMYK TIFF 출력**은 [CMYK 안내](CMYK.md)를 참고하세요. 원본 편집 속성은 `.moruproj`에도 함께 보관해야 합니다.

## 사진 현상과 사용자 브러시 저장

Preview 13의 **사진 현상**은 이미 가져온 RGB 8비트 이미지에 적용하는 비파괴 보정입니다. 카메라 RAW 파일을 해독하는 기능이나 Adobe Camera Raw와 같은 결과를 보장하는 호환 엔진은 아닙니다. 지원하는 사진·PDF·AI·PSD·CAD를 이미지로 가져온 뒤 같은 보정을 적용할 수 있습니다.

- `.moruproj`는 사진 현상의 13개 조절값·마스크·레이어 속성을 저장합니다. 이 조정 레이어가 있는 작업은 **Preview 13 이상**에서 다시 열어 편집하세요.
- 원작 `.comp`는 사진 현상 조정을 지원하지 않으므로 해당 레이어가 있으면 내보내기를 거부하고 안내합니다. 조절값 보관에는 `.moruproj`, 외형 전달에는 합성 이미지·PDF·합성 PSD를 사용하세요. 기본 픽셀 레이어 PSD는 기존과 같이 조정 레이어가 있는 문서를 지원하지 않습니다.
- 사용자 브러시 모양은 PNG/JPEG/BMP/TIFF에서 가져옵니다. 파일 **32 MiB 이하**, 한 변 65,535px·전체 536,870,897픽셀 이하가 적용되며, 긴 변 최대 256px의 모양으로 축소해 `%LOCALAPPDATA%\Morupixel\Brushes`에 보관합니다. 다중 프레임 이미지는 첫 프레임만 사용하고 Adobe `.abr`는 지원하지 않습니다.
- 브러시 라이브러리는 개인 설정이며 `.moruproj`에 들어가지 않습니다. 이미 그린 획은 픽셀로 저장되므로 다른 PC에서도 보입니다. 다른 PC에서 같은 브러시를 새로 사용하려면 원본 이미지를 다시 가져오거나 위 사용자 브러시 폴더를 옮기세요.

## 실행 환경과 한도

Windows 10 버전 2004(빌드 19041) 이상 또는 Windows 11, x64가 필요합니다. PDF 렌더링은 Windows 내장 엔진을 사용하고 DWG/DXF 리더는 앱에 포함합니다. 별도 Adobe·AutoCAD 설치, 외부 변환 프로그램, 업로드 서비스는 필요하지 않습니다.

PDF·AI·PSD/PSB·DWG/DXF 입력 파일은 최대 **8GiB**입니다. 일반 PNG·JPEG 등의 이미지 열기에는 별도 파일 바이트 제한이 없습니다. 모든 입력에는 한 변 **65,535px**, 전체 **536,870,897픽셀(약 536.9MP)**, 최대 32,768개 객체·그룹(이미지·조정 레이어는 최대 128개), 레이어 픽셀/마스크 합계 **8GiB**의 문서 한도가 적용됩니다. PDF/PSD 및 기존 CAD 레이어별 모드의 결과 레이어 한도는 128개입니다. 가로·세로와 전체 픽셀 제한을 모두 만족해야 합니다. `.moruproj`의 레이어별 PNG 항목은 최대 **4GiB**, 문서 메타데이터는 최대 **32MiB**까지 읽습니다.

PSB 입력은 위 이미지 한도를 사용합니다. **PSD 출력은 한 변 30,000px**의 형식 한도를 유지하며 PSB 출력은 지원하지 않습니다. CAD 미리보기 긴 변은 256~4,096px입니다. 암호 PDF는 암호를 해제한 사본이 필요합니다.

실행 취소는 최대 50개 항목과 별도 보관 픽셀 **192MiB** 범위이므로 큰 편집은 실행 취소 기록을 남기지 못할 수 있습니다. 디코딩·합성·편집에 추가 전체 크기 버퍼가 필요하며, 실제로 열고 편집할 수 있는 크기는 사용 가능한 메모리·코덱·작업 내용에 따라 달라집니다.
