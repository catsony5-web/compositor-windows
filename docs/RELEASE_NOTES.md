# Morupixel 0.2.0 Preview 1

Layers, color, and composition — in a Windows workspace.

This preview brings layer groups and masks, adjustment layers, selection and retouching tools, local AI background removal, and ICC-managed CMYK TIFF export.

[Download for Windows x64](https://github.com/catsony5-web/compositor-windows/releases/download/v0.2.0-preview.1/Morupixel-0.2.0-preview.1-win-x64.zip) · [Website](https://morupixel.arch-t.chatgpt.site/)

Extract the entire ZIP and run `Morupixel.exe`. The AI tool requires the [Microsoft Visual C++ x64 runtime](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).

Development preview · Unsigned · sRGB editing with CMYK TIFF output.
