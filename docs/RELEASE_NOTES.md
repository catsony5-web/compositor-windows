# 0.1.0-preview.2

Preview 2는 레이어 선택 동작을 더 직접적이고 예측 가능하게 다듬은 선택 UX 수정 릴리스입니다. 이동 도구의 **자동 선택**을 켜고 캔버스의 보이는 픽셀을 클릭하면 해당 위치에서 가장 위에 보이는 레이어가 선택됩니다. 투명 픽셀과 마스크로 완전히 가려진 픽셀은 통과하며, 회전·배율·뒤집기가 적용된 레이어도 화면에 보이는 위치대로 선택합니다. 잠긴 레이어는 선택할 수 있지만 이동은 잠금 해제 전까지 차단됩니다.

레이어 목록에서는 썸네일, 이름, 행의 빈 공간을 클릭해 레이어를 선택합니다. 다른 레이어의 표시 체크박스나 잠금 버튼을 조작해도 현재 선택은 유지됩니다. 자동 선택을 끄면 캔버스를 클릭해도 목록에서 고른 레이어가 유지됩니다.

**자동 선택은 캔버스 레이어 picking 기능이며, 색상이나 영역을 고르는 마법봉 도구가 아닙니다.** 마법봉, 올가미와 다각형 올가미는 아직 지원하지 않습니다.

## Preview 2 검증 상태

- 소스와 배포 EXE의 자동 테스트 각각 46개 통과
- Windows 11에서 캔버스의 달 클릭, 레이어 행의 이름·썸네일·빈 공간 선택, 다른 레이어 표시 전환 시 선택 유지, 자동 선택을 끈 상태의 선택 유지 확인

자세한 선택 UX 검증은 [SELECTION_FIX.md](SELECTION_FIX.md)에 기록했습니다. Preview 1의 완료된 배포 검증 기록은 [VALIDATION.md](VALIDATION.md)에 그대로 보존되어 있습니다.

## 다운로드와 실행

[0.1.0-preview.2 Windows x64 ZIP](https://github.com/catsony5-web/compositor-windows/releases/tag/v0.1.0-preview.2)을 폴더에 모두 압축 해제하고 `Compositor.Windows.exe`를 실행합니다. ZIP에는 .NET 런타임이 포함됩니다. 관리자 설치는 필요하지 않습니다. 이 프리뷰는 코드 서명이 되어 있지 않습니다.

## 알려진 제한

- PSD 및 원본 Mac 작업 파일과 호환되지 않습니다.
- 레이어 그룹, 클리핑 마스크, 조정 레이어, 곡선, 올가미·다각형 올가미·마법봉, 복제 도장·복구, AI 배경 제거, 콘텐츠 인식 채우기, 여러 문서 탭은 미지원입니다.
- 텍스트는 추가할 때 픽셀로 변환됩니다. 보정은 선택 레이어에 직접 적용합니다.
- EXIF 자동 회전, ICC 색상 관리, CMYK는 미지원입니다.
- 소수 픽셀 이동·회전 경계의 안티앨리어싱과 큰 이미지의 편집 성능은 개선이 필요합니다. 가우시안 흐림은 원본 레이어 경계를 확장하지 않습니다.
- 최대 32개 레이어, 한 변 8,192px, 이미지 전체 16,777,216픽셀을 지원합니다.

# 0.1.0-preview.1

첫 번째 비공식 Windows 프리뷰입니다. Robbie Tilton의 [Compositor](https://github.com/robbietilton/Compositor)를 바탕으로 C#과 WPF에서 재구현했으며, 원작의 전체 기능과 동등한 버전은 아닙니다.

## 포함 기능

- 레이어, 불투명도, 10개 혼합 모드와 래스터 마스크
- 브러시, 지우개, 사각형·타원 선택, 자르기, 도형, 그라데이션, 래스터 텍스트
- 레이어 이동·크기·회전·반전, 실행 취소·다시 실행
- 레벨, 노출, 채도, 흑백, 반전, 가우시안 흐림
- 레이어를 보존하는 `.cwproj` 저장, PNG/JPEG 내보내기
- 한국어 Windows 데스크톱 UI와 단축키
