# 사용 목적 (작업 화면 프로필)

사용 목적은 사용자가 하는 일에 맞춰 **무엇을 먼저 보여 줄지**만 바꾼다. 기능을 숨기거나 빼지 않는다. 도구막대의 모든 도구, 오른쪽 패널의 모든 묶음, 메뉴와 명령 팔레트(Ctrl+K)의 모든 명령은 어느 사용 목적에서도 그대로 쓸 수 있다.

## 고르는 곳

- **시작 화면**: 제목 아래 `사용 목적 [기본 | 건축학과]` 세그먼트. 처음 실행하면 아래에 "하는 작업에 맞게 고르세요…" 안내가 한 줄 보이고, 하나를 고르면(이미 선택된 기본을 눌러도) 사라진다. 대화상자나 반복 알림은 띄우지 않는다.
- **보기 → 사용 목적**: 같은 선택지를 체크 항목으로 둔다. 리본에서는 보기 탭의 `사용 목적` 묶음이 되고, 명령 팔레트에서는 `보기 › 사용 목적` 분류로 찾을 수 있다("건축", "사용목적").
- 고른 값은 작업 공간 배치(`%LOCALAPPDATA%\Morupixel\workspace.json`의 `Profile`)에 저장된다. 모르는 값은 저장·복원할 때 버리고 기본으로 둔다. 고른 적이 없으면 저장하지 않는다(`null`).

## 기본

지금까지의 편집기 그대로다. 표의 모든 선택이 비어 있어(`null`) 도구 묶음, 오른쪽 첫 탭(사진 편집: 사진 현상 · 조정 레이어 · 선택과 마스크 · 리터치 / 디자인: 만들기 · 캔버스에 정렬 · 배치와 그룹 · 색상과 내보내기), 탭 이름(보정/디자인), 시작 화면 빠른 시작이 바뀌지 않는다. 자체 검사가 기본의 패널·도구 순서를 원래 만드는 함수의 결과와 비교한다.

## 건축학과

평면도(DWG/DXF/PDF)를 가져와 발표 보드를 만드는 흐름에 맞춘다.

| 항목 | 내용 |
| --- | --- |
| 작업 모드 | 고를 때 디자인 모드로 바꾼다(벡터 도면을 확대 배율에 맞춰 선명하게 그림). 저장된 배치를 복원할 때는 저장된 모드를 따른다. |
| 오른쪽 첫 탭 | 이름 `도면`(패널 이름 `도면 작업`). 순서: **선 정리 → 리터치 → 배치와 그룹 → 사진 보정(사진 현상) → 조정 레이어** → 모드별 나머지(디자인: 만들기 · 캔버스에 정렬 · 색상과 내보내기, 사진 편집: 선택과 마스크). |
| 선 정리 | `선 정리 다시 적용`, `도면 가져오기`, `도면 레이어 보기`, `치수·문자 표시 전환`, `해치 재질 표시 전환` |
| 리터치 | 복구 브러시 · 복제 도장 · 흐림 브러시 · 주변으로 채우기 · 지우개 · 브러시 설정 |
| 도구막대 | 선택(이동 · 마술봉 · 다각형 올가미 · 사각 선택 · 올가미 · 타원 선택) → 리터치(복구 · 복제 도장 · 흐림 · 지우개 · 브러시 · 스머지 · 액화) → 보드(텍스트 · 사각형 · 타원 · 대지 · 자르기) → 색상(버킷 · 스포이트 · 그라데이션) → 보기(손) |
| 시작 화면 빠른 시작 | A1 가로 150 DPI · A2 가로 200 DPI · A3 가로 300 DPI(흰 배경) · 도면 가져오기 |

### 선 정리 다시 적용

가져오기 창의 "레이어별 선 굵기·농도 맞추기"를 끄고 가져온 도면에도 나중에 같은 정리를 적용한다(`src/Engine/DrawingLineCleanup.cs`).

- 대상: 선택한 레이어와 그 안의 벡터 경로 레이어. 선택한 레이어에 도면 선이 없으면 문서 전체.
- 역할: 레이어에 남아 있는 CAD 레이어 이름으로 찾는다. 객체별 가져오기는 CAD 레이어 폴더의 원본 이름, 레이어별 가져오기는 레이어 이름. 문서 이름으로 만든 바깥 폴더 이름은 쓰지 않는다. 역할은 `DrawingCleanup.Classify`, 굵기·농도는 `DrawingCleanup.Weight`/`Tone`으로 가져오기 정리와 같다(자체 검사가 가져오기 정리 결과와 벡터 원본을 바이트 단위로 비교).
- 역할을 알 수 없는 레이어(`기타`), 잠긴 레이어, PDF 원본 벡터는 그대로 둔다. 이미 정리된 도면에 다시 적용하면 기록이 늘지 않는다. 한 번의 실행 취소로 되돌린다.
- 해치 재질은 다시 만들지 않는다. 가져온 뒤에는 해치 영역이 남지 않기 때문이다. 가져올 때 채운 재질 레이어는 `해치 재질 표시 전환`으로 한 번에 숨기거나 표시한다.
- `치수·문자 표시 전환`은 치수·문자 역할의 CAD 레이어 폴더(또는 레이어)를 한 번에 숨기거나 다시 표시한다. 발표용 평면에서 치수를 빼는 흔한 작업이다.

## 새 사용 목적 추가하기

모든 선택은 `src/App/UserProfiles.cs`의 표 한 줄에 모인다. `if (건축학과)` 같은 분기를 여러 파일에 흩지 않는다.

1. `UserProfiles`에 `UserProfile` 한 줄을 만들고 `All`에 넣는다. `Id`는 저장용 영문 식별자(바꾸지 않음), `Name`·`Summary`는 한국어 원문(번역표에 추가).
2. 필요한 항목만 채운다. 비워 둔 항목은 기본 편집기를 따른다.
   - `TabCaption`, `PaneCaption`: 오른쪽 첫 탭 이름.
   - `PhotoSections`, `DesignSections`: 첫 탭 묶음 제목 순서. 제목은 `Theme.Section` 제목 그대로다. 없는 제목은 건너뛰고, 그 모드 패널의 나머지 묶음은 원래 순서로 뒤에 붙는다. 그래서 다른 작업이 `BuildPhotoActions`/`BuildDesignActions`에 새 묶음이나 버튼을 추가해도 모든 사용 목적에 나타난다. 새 묶음을 특정 위치에 두려면 제목을 목록에 넣기만 하면 된다.
   - `UserProfiles.PhotoLead`(`사진 보정`): 사진 패널 맨 앞의 사진 현상 카드. 다른 묶음 뒤로 옮기면 이 제목이 붙는다.
   - 사용 목적 전용 묶음은 `MainWindow.Profiles.cs`의 `BuildProfileSections`에 만든다. 모드 패널과 같은 제목이면 그 묶음을 대신한다(건축학과의 `리터치`는 사진 패널 리터치에 흐림 브러시·지우개를 더한 것).
   - `ToolGroups`: 도구막대 묶음. 빠뜨리거나 두 번 넣은 도구는 `기타` 묶음으로 뒤에 붙어 사라지지 않는다.
   - `DesignWorkspace`: 고를 때 바꿀 작업 모드.
   - `QuickSizes`, `QuickDrawingImport`: 시작 화면 빠른 시작 크기와 도면 가져오기 칸.
3. 리본 아이콘은 `Glyph`(`Theme.Glyphs`)를 쓴다.
4. `src/Tests/MainWindow.UserProfileTests.cs`에 순서·도구·저장 검사를 추가하고, `MainWindow.Profiles.cs`의 `RenderProfilePreviews`에 오프스크린 캡처를 추가한다.

## 검수 캡처

`--render-studio-previews`가 `profile-architecture-startup.png`(시작 화면), `profile-architecture-editor.png`·`profile-architecture-cleanup.png`(평면 예시를 가져온 편집기, 선 정리 전후), `profile-architecture-actions.png`·`profile-architecture-photo-actions.png`(디자인/사진 편집 모드의 첫 탭)를 만든다. 기본 시작 화면은 `startup.png`에서 처음 실행 안내와 함께 확인한다.
