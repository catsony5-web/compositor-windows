# AI로 재료 적용하기

Preview 26의 MCP 규약 3은 준비된 이미지를 도면의 2D 영역에 반복 배치합니다. 연결한 AI에게 “선택한 바닥에 이 목재 이미지를 적용하고, 결 방향을 90도 돌려줘”처럼 요청할 수 있습니다. Codex·Claude Code 연결 방법은 [AI 연결](AI_CONNECTION.md)을 참고하세요.

## 작업 흐름

1. AI가 사용 가능한 이미지 생성 도구로 재료를 준비하거나 기존 PNG·JPEG·TIFF 등 Windows 이미지 디코더가 읽을 수 있는 파일을 지정합니다.
2. `register_material`로 원본을 등록하고 반환된 `materialId`를 사용합니다. 경로는 Morupixel이 실행 중인 PC의 절대 경로입니다.
3. `define_region`으로 적용 경계를 캡처합니다. `selection`은 현재 선택 영역, `closed_layer`는 닫힌 도형·CAD 경로의 `layerId`, `polygon`은 문서 픽셀 좌표의 점 목록을 사용합니다. 다각형의 `holes`로 기둥·중정 등을 제외할 수 있습니다.
4. `apply_material`에 재료와 영역 ID, 반복 크기를 전달합니다. 여러 영역은 `apply_batch`로 미리 검증하고 한 번에 적용합니다.
5. `preview`로 확인한 뒤 `update_material`로 크기·방향·위치나 재료 원본을 바꿉니다. `save_project`는 재편집 가능한 프로젝트, `export_image`는 합성 이미지를 저장합니다.

모든 변경은 현재 `documentId`와 `expectedRevision`을 사용합니다. MCP에서는 `sessionId`도 필요합니다. 아래는 명령별 추가 인자 예시이며 자리표시자 ID를 앞선 응답의 값으로 바꿉니다.

```json
{
  "register_material": {
    "name": "밝은 오크", "path": "C:\\Work\\oak.png",
    "source": "사용자가 준비한 재료", "tileable": true
  },
  "define_region": { "name": "선택한 바닥", "source": "selection" },
  "apply_material": {
    "materialId": "<등록 응답의 materialId>",
    "regionId": "<영역 응답의 regionId>",
    "tileWidth": 160, "tileHeight": 160, "angle": 90
  },
  "update_material": { "layerId": "<적용 응답의 layerId>", "offsetX": 12 }
}
```

위 JSON은 네 번의 호출에 사용할 인자 안내이며 하나의 실행 요청이 아닙니다. 매번 성공 응답의 새 revision으로 다음 요청을 구성합니다. `query_materials`와 `query_regions`는 기본 20개·최대 50개씩 조회하며, 다음 페이지에는 첫 응답의 revision과 nextOffset을 사용합니다.

## 편집과 보존

- 맵핑은 독립된 재료 레이어로 추가되며 **사진 레이어** 탭에 표시됩니다(도면 정리로 만든 해치 재질도 같음). 원래 도면 객체를 바꾸지 않습니다. 기본 혼합은 Multiply이며 선을 겹쳐 볼 수 있습니다. 필요하면 apply_material의 blend 또는 set_layer로 바꿉니다.
- 패턴 크기와 위치는 레이어 내부 픽셀 단위, angle은 도 단위입니다. 도면의 실제 mm·CAD 축척을 추정하지 않습니다.
- 경계는 벡터로, 재료 이미지는 원본 픽셀로 유지합니다. 일반 확대·출력은 원본에서 다시 렌더링합니다. 원근 변형은 기존 래스터 처리 범위를 따릅니다. 원본 이미지 자체의 해상도 한계는 유지됩니다.
- 적용 경계는 캡처 당시의 모양입니다. 이후 원래 CAD 객체를 옮겨도 맵핑이 자동으로 따라가지는 않습니다. 재료 레이어 자체는 일반 이동·회전·마스크·불투명도 조절을 지원합니다.
- 선택 영역은 50% 윤곽을 가져오며 내부 구멍을 보존합니다. 선택의 부드러운 페더 농도는 기하 경계로 저장하지 않습니다.
- 열린 CAD 선, 마스크·원근·클리핑이 있는 객체, 잘리는 일반 그룹의 객체는 closed_layer로 추측하지 않습니다. 이 경우 실제 선택 영역이나 명시적인 다각형을 사용합니다.
- 재료 등록·영역 지정·맵핑·패턴 변경은 실행 취소할 수 있습니다. 재료 적용·패턴 변경을 묶으면 한 번의 실행 취소로 되돌립니다. 픽셀 브러시 편집을 위해 래스터화하면 해당 레이어의 패턴 편집 속성이 픽셀로 변환되며 실행 취소로 복원할 수 있습니다.

재료 또는 영역이 있는 `.moruproj`는 **포맷 6**으로 저장하며 Preview 26 이상에서 다시 엽니다. 원본 이미지가 프로젝트에 내장되므로 외부 이미지 파일이 이동해도 유지됩니다. 재료가 없는 일반 문서는 기존 저장 포맷을 유지합니다. 구버전에 전달할 때는 PNG 등으로 별도 출력하세요.

## 해치 패턴

재질 이미지 외에 도면용 **선 해치 패턴** 19종(잔디·풀밭·모래·성긴 점·짧은 빗금·짧은 가로선·둥근 점·작은 포장석·가로줄·고운 점·판석·자연석·자갈·콘크리트·벽돌·사선·교차 사선·사각 격자·단열재)을 기본으로 제공합니다.

- **고르기**: 선택 영역 재질의 [재질 이미지 | 해치 패턴] 탭, 재질 레이어 속성의 **다른 재질로 바꾸기**, 도면 가져오기의 **선 해치 패턴으로 채우기**(CAD 해치 이름·레이어 이름으로 패턴을 고름, SOLID는 단색), AI 연결의 `query_patterns`에서 고릅니다. 패턴은 바탕이 투명한 잉크 선이라 곱하기로 아래 색과 선이 그대로 보입니다.
- **저장**: 패턴은 예약된 ID와 `morupixel:pattern/<키>@1` 원본 표시를 가진 일반 재료입니다. 쓰인 패턴만 문서 라이브러리에 들어가며 256px 대체 이미지가 함께 저장됩니다. 저장 포맷은 6 그대로입니다.
- **선명한 확대**: 화면 배율과 내보내기 해상도(2x·사용자 지정 배율 포함)에 맞춰 선을 다시 그리므로 400% 이상 확대해도 흐려지지 않습니다. 반복 타일은 화면 픽셀에 딱 맞는 크기로 그려 캐시(최대 128MiB)에서 다시 쓰고, 가로·세로 선은 픽셀 중심에 맞춰 선명하게 그립니다. 한 반복이 2048px보다 커지면 타일 대신 벡터로 보이는 부분만 그립니다. 축소해서 볼 때 너무 가는 선·점은 최소 굵기로 그리되 잉크를 그만큼 옅게 해 100%와 같은 농도로 보입니다.
- **크기·비율·굵기**: 재질 레이어 속성의 **패턴 크기와 방향**에서 바꿉니다. 크기 %는 무늬 간격과 길이를 함께(100% = 새 재질 기본 크기), 세로 비율 %는 무늬 모양은 그대로 둔 채 세로 간격만 바꿉니다(재질 이미지는 세로로 늘어남). 선 굵기 %는 선과 점 굵기를, 잉크 색은 선 색을 바꿉니다. 선 굵기의 기준은 문서 픽셀이며 타일 크기에 비례하지 않습니다. 크기 %와 세로 비율 % 슬라이더는 로그 눈금이라 100%가 가운데에 있습니다. 판석·자연석은 한 반복에 돌이 많이 들어가도록 기본 크기가 두 배이며, 다른 재질로 바꿔도 크기 %는 그대로 유지됩니다. 슬라이더를 움직이는 동안 바로 보이고, 손을 떼면 한 번의 실행 취소 단계가 됩니다. 회전은 레이어 원점을 기준으로 합니다.
- **이전 버전**: 이전 Morupixel은 패턴을 일반 재질 이미지로 보고 저장된 256px 타일을 반복합니다(잉크 색·선 굵기는 무시). 새 버전은 알 수 없는 속성이 있는 파일도 엽니다.
- **고정된 모양**: 한 번 배포한 `@1` 패턴의 모양은 바꾸지 않습니다. 새 모양은 새 패턴이나 새 생성 버전으로 추가합니다.
- **즐겨찾기**: 견본에 마우스를 올리면 오른쪽 위에 별이 나타납니다. 별을 누르거나 견본의 오른쪽 클릭 메뉴에서 **즐겨찾기에 추가**하면 패턴 탭 맨 앞 **즐겨찾기** 묶음에 별을 누른 순서대로 놓입니다(기본 패턴·내 패턴 모두). 즐겨찾기는 작업 공간 배치(`%LOCALAPPDATA%\Morupixel\workspace.json`의 `PatternFavorites`)에 저장됩니다.
- **내 패턴**: 패턴 탭의 **이미지로 패턴 추가…**로 스캔하거나 그린 해치 타일(PNG·JPEG·BMP·TIFF·WebP)을 선 패턴으로 바꿉니다. 어두운 선은 잉크, 밝은 종이는 투명이 되며, 선 인식 기준은 이미지 밝기에서 자동으로 정하고(조절 가능) 종이 결과 얼룩은 지웁니다. **가장자리 빈 여백 자르기**는 그림 둘레의 빈 종이를 잘라 반복 간격을 맞춥니다. 큰 이미지는 긴 변 1,024px로 줄여 저장합니다. 만든 패턴은 기본 패턴처럼 반복·크기·회전·잉크 색·선 굵기(선 가장자리를 고르게 넓히거나 좁힘)와 바탕색을 쓰며, 이 PC의 `%LOCALAPPDATA%\Morupixel\Patterns`에 보관됩니다(최대 64개). 견본의 오른쪽 클릭 메뉴에서 이름을 바꾸거나 삭제합니다. 내 패턴은 이미지에서 온 선이라 크기 %를 바꾸면 선 굵기도 함께 바뀝니다.
- **문서에 함께 저장**: 쓰인 내 패턴은 타일이 문서 안에 들어가므로(원본 표시 `morupixel:line-pattern@1`) 그 패턴이 없는 PC에서도 그대로 열리고, 패턴 탭 **내 패턴**에 나타나 **내 패턴에 저장**으로 보관할 수 있습니다. 내 패턴에서 삭제하거나 이름을 바꿔도 이미 쓴 문서는 바뀌지 않습니다. 이전 Morupixel은 기본 잉크 색의 재질 이미지로 보여 줍니다.
- **바탕색**: 패턴 레이어 속성의 **바탕색**으로 선 아래 영역을 한 색으로 채웁니다. 기본값은 **없음**(투명)이며 ✕로 되돌립니다. 곱하기 레이어이므로 바탕색도 아래 색과 곱해집니다. 화면·PNG·PDF·.psd 내보내기와 레이어 썸네일에 같이 나타납니다. 이전 파일은 바탕색 없이 열리고, 이전 Morupixel은 바탕색을 무시합니다.

AI 연결에서는 `query_patterns`(표면 `general`·`wall`·`floor`·`ground`별 순서)로 `materialId`를 받아 `apply_material`·`update_material`에 넘기면 라이브러리에 자동으로 등록됩니다. 패턴 전용 인자는 `ink`(`#RRGGBB`, 알파 01~FF의 `#AARRGGBB`, `default`)와 `lineWeight`(0.1~8)입니다.

```json
{
  "query_patterns": { "surface": "ground" },
  "apply_material": {
    "materialId": "<query_patterns 응답의 잔디 materialId>",
    "regionId": "<영역 응답의 regionId>",
    "tileWidth": 64, "tileHeight": 96, "lineWeight": 1.2
  },
  "update_material": { "layerId": "<적용 응답의 layerId>", "ink": "#FF4A5A48" }
}
```

## 지원 범위

문서당 원본 64개·256MiB, 영역 템플릿 128개까지 보관합니다. 재료 원본과 적용 영역의 캐시는 각각 한 변 8,192px·전체 16,777,216픽셀 이하입니다. 인코딩된 원본 파일은 96MiB 이하, 다각형은 내부 윤곽 16개·전체 점 2,048개 이하, 저장 경로는 64KiB 이하입니다. 문서 전체 메모리 제한과 이미지·조정·재료 레이어 합계 128개 제한도 적용됩니다.

tileable은 이미지가 자연스럽게 반복된다는 호출자의 선언이며 자동 이음새 검사나 생성 기능은 아닙니다. 이미지 생성·서비스 구독·인증은 연결한 AI 프로그램과 제공자가 담당합니다. 이 도구는 2D 패턴 적용을 제공하며 3D UV, 자동 방 인식, 실측 축척 설정은 제공하지 않습니다.
