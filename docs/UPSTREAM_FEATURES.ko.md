# Compositor 원작 기능 지원 비교

이 문서는 Morupixel Windows 확장판에서 기능을 설계·검증할 때 기준으로 삼기 위해, 원작 Compositor의 소스 스냅샷 [`9d5582dc59429501e270828b27879de9ca30a853`](https://github.com/robbietilton/Compositor/tree/9d5582dc59429501e270828b27879de9ca30a853)을 읽기 전용으로 조사한 결과를 기록한다.

여기서 “원작 지원”은 메뉴 이름만 존재한다는 뜻이 아니라 해당 스냅샷에서 UI와 처리 경로를 소스로 확인했다는 뜻이다. Morupixel의 같은 이름 기능은 Windows용 C# 코드로 별도 구현하는 확장 기능이다. 이 문서는 Morupixel 기능의 현재 완료를 주장하지 않으며, 원작과 결과 품질·정확도·성능이 동등하다는 검증도 아직 하지 않았다.

## Windows 확장판의 색상 출력 목표

Morupixel Windows 확장판에서는 원작에 없는 CMYK 출력 기능을 추가하고 있다. 사용자 요구로 확정된 범위는 단순한 “CMYK 파일 저장”이 아니라 다음을 함께 제공하는 **ICC 기반 인쇄 출력과 미리보기**다.

- 출력 ICC 프린터 프로파일 선택
- 선택한 프로파일을 적용한 인쇄용 CMYK 변환·출력
- 출력 프로필 변환 결과의 화면 미리보기
- 프로파일과 변환 조건을 알 수 있는 명확한 UI

원작의 입력 시 sRGB 정규화는 이 요구를 충족하지 않는다. Windows 확장판의 ICC/CMYK 구현은 원작 기능을 이식하는 작업이 아니라 새 색상 관리 경로를 설계하는 작업이며, 출력 프로파일 적용, 미리보기 일치도, 임베드 결과, 인쇄소 도구와의 호환성을 별도로 검증해야 한다.

## 해석 시 주의사항

- 원작의 “수동 회전 지원”은 레이어·선택·그룹 변환을 뜻한다. 캔버스 전체 회전은 별도 기능이며 해당 스냅샷에는 없다.
- 원작의 “ICC 지원”은 태그 입력을 고정 sRGB 작업공간으로 변환하는 기본 처리다. 프린터 ICC 선택, CMYK 출력, soft proof를 포함하는 전체 색상 관리가 아니다.
- 마술봉은 색상 유사 픽셀 선택 도구다. 이동 도구의 자동 레이어 선택은 캔버스를 클릭해 레이어를 고르는 별도 기능이다.
- Morupixel에 대응 기능 코드가 존재하더라도 원작과의 품질 동등성은 기능별 샘플 이미지, 경계 사례, 저장 후 재열기, 내보내기 결과를 비교하기 전까지 확인된 것으로 보지 않는다.
